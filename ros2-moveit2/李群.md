# 概念
## 1、群
群，定义为 (G, ·) ，表示集合 + 运算，即集合 + 运算共同构成一个群。其中：

- G：一个集合，其中的元素就是群的成员；
- ·：定义在 G 上的任意一种运算。同一个集合配不同运算，可能是完全不同的群；\

一个群，需要满足 4 个性质：
- 封闭性：a·b ∈ G
- 结合律：(a·b)·c = a·(b·c)
- 单位元：存在 e ∈ G，使对任意 a 都有：e · a = a · e = a，即单位元（identity element）是群里的“什么都不做”的元素，和任何元素运算，结果都不变
- 逆元：每个 a 都有 a⁻¹，使 a · a⁻¹ = e

## 2、李群、李代数
李群（Lie group，源自挪威数学家 Sophus Lie） 要同时满足两个条件：

是群：有封闭的二元运算、单位元、逆元（上一轮讲的 (G, ·) 那套）；
是光滑流形：元素可以用有限个实数参数连续描述，而且群运算和求逆都是**光滑（可微）**的。

"光滑"这个条件就是关键：它让你能在群上求导，从而得到切空间 = 李代数，进而有 exp/log 映射



设 G 是李群，H ⊆ G。H 叫 李子群，需要同时满足：

代数上：H 对 G 的群运算封闭（子群）——含单位元、逆元、乘法封闭；
几何上：H 是 G 的子流形（有自己的一套光滑坐标）；
相容性：包含映射 H ↪ G 是光滑的，且 H 上的群运算（乘法和求逆）作为映射都是光滑的。



李群家族\

## 3、欧几里德群
欧几里德群 $E(n)$：n 维欧氏空间中所有保持距离的变换（等距变换），包括旋转、平移、镜像；

特殊欧几里德群 $SE(n)$：欧几里德群中旋转部分行列式为 +1 的那一半（排除镜像）。矩阵表示为：

```
T = [ R  t ]      
    [ 0  1 ]      
```

其中，det R = +1，即排除掉欧几里德群中镜像的部分。





## 、雅可比矩阵
雅可比矩阵（Jacobian matrix）
定义
设有一个向量函数


F : ℝⁿ → ℝᵐ,    F(q) = (F₁(q), F₂(q), …, Fₘ(q))
它的雅可比矩阵是全部一阶偏导数排成的 m × n 矩阵：


        ⎡ ∂F₁/∂q₁  ∂F₁/∂q₂  …  ∂F₁/∂qₙ ⎤
J(q) =  ⎢ ∂F₂/∂q₁  ∂F₂/∂q₂  …  ∂F₂/∂qₙ ⎥
        ⎢    ⋮         ⋮       ⋱     ⋮   ⎥
        ⎣ ∂Fₘ/∂q₁  ∂Fₘ/∂q₂  …  ∂Fₘ/∂qₙ ⎦
即：


Jᵢⱼ = ∂Fᵢ / ∂qⱼ        （第 i 个输出对第 j 个输入的偏导）

关键性质
性质	内容
尺寸	m × n（输出维数 × 输入维数）
链式法则	J(g∘f) = J_g · J_f
方阵时	det(J) 反映局部体积缩放，det ≠ 0 表示局部可逆
秩	rank(J) = 输出对输入变化的有效独立方向数
零空间	null(J) = 一阶意义上不改变输出的输入方向

Gram 矩阵（Gram matrix / Gramian）
定义
给定一组向量 v₁, v₂, …, vₖ 和一个内积 ⟨·,·⟩，Gram 矩阵是它们两两内积排成的 k × k 矩阵：


        ⎡ ⟨v₁,v₁⟩  ⟨v₁,v₂⟩  …  ⟨v₁,vₖ⟩ ⎤
G =     ⎢ ⟨v₂,v₁⟩  ⟨v₂,v₂⟩  …  ⟨v₂,vₖ⟩ ⎥
        ⎢    ⋮        ⋮      ⋱     ⋮    ⎥
        ⎣ ⟨vₖ,v₁⟩  ⟨vₖ,v₂⟩  …  ⟨vₖ,vₖ⟩ ⎦
即：


Gᵢⱼ = ⟨vᵢ, vⱼ⟩
用矩阵写
内积取标准欧氏内积 ⟨u,v⟩ = uᵀv 时：

向量怎么放	Gram 矩阵
v₁…vₖ 作为 列 组成 A (n×k)	G = AᵀA （k×k）
v₁…vₖ 作为 行 组成 A (k×n)	G = AAᵀ （k×k）
上面两种形式算的是同一件事——对谁做 Gram，取决于向量是列还是行。

核心含义：度量向量之间的「长度」和「夹角」
元素	含义
对角 Gᵢᵢ = ‖vᵢ‖²	第 i 个向量的长度平方
非对角 Gᵢⱼ = vᵢᵀvⱼ	第 i、j 个向量的内积（夹角 / 重叠程度）
G 的大小	衡量这组向量有多"相关"
关键性质
性质	内容
对称	G = Gᵀ
半正定	对任意 x：xᵀGx = ‖Σᵢ xᵢvᵢ‖² ≥ 0
秩	rank(G) = rank{v₁,…,vₖ}（这组向量的张成维数）
正定条件	G 正定 ⟺ 这组向量线性无关
行列式	det(G) = 这组向量张成的平行多面体体积的平方
与 SVD 的关系	G = AᵀA 或 AAᵀ 的非零特征值 = A 奇异值的平方

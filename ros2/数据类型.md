

# 时钟

在 ROS2 中的部分场景中需要使用时间辍，如数据时间辍、日志时间辍等，本章介绍与 ROS2 相关的时间。

1、std::chrono::system_clock && std::chrono::steady_clock 

| ROS2 | C/C++层 | 内核时钟 | 起点 | 能否被调整 | 备注 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| RCL_SYSTEM_TIME | rcutils_system_time_now（C） | CLOCK_REALTIME | 标准定义为Unix纪元 | NTP step + slew、clock_settime | 可以倒退 |
|  | std::chrono::system_clock（C++） | CLOCK_REALTIME | 标准定义为Unix纪元 | NTP step + slew、clock_settime | 可以倒退 |
| RCL_STEADY_TIME | rcutils_steady_time_now（C） | CLOCK_MONOTONIC_RAW | 无标准定义，实际定义为系统启动时刻（不含休眠时间） | 无法 | 速率跟随晶振，长期会和真实秒长偏离 |
|  | std::chrono::steady_clock（C++） | CLOCK_MONOTONIC | 无标准定义，实际定义为系统启动时刻（不含休眠时间） | NTP slew | 速率跟随晶振，长期被 NTP 拉向真实秒长 |
|  |  | CLOCK_BOOTTIME | 无标准定义，实际定义为系统启动时刻（包含休眠时间） | NTP slew | 速率跟随晶振，长期被 NTP 拉向真实秒长 |

	std::chrono::system_clock → CLOCK_REALTIME	墙上时间，会被 NTP/手动改时间拨动，可能倒退	日志、std::time、部分旧代码
	std::chrono::steady_clock → CLOCK_MONOTONIC	严格单调，只增不减，不受系统时间调整影响	create_wall_timer、initPeriod/waitPeriod、超时/测时长

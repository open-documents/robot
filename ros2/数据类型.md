

# 时钟

在 ROS2 中的部分场景中需要使用时间辍，如数据时间辍、日志时间辍等，本章介绍与 ROS2 相关的时间。

1、std::chrono::system_clock && std::chrono::steady_clock 

| ROS2 | C++层 -> 内核值 |  |
| :---: | :---: | :---: |
| RCL_SYSTEM_TIME | std::chrono::system_clock |  |
|       |       |       |

ROS 2 			
	std::chrono::system_clock → CLOCK_REALTIME	墙上时间，会被 NTP/手动改时间拨动，可能倒退	日志、std::time、部分旧代码
	std::chrono::steady_clock → CLOCK_MONOTONIC	严格单调，只增不减，不受系统时间调整影响	create_wall_timer、initPeriod/waitPeriod、超时/测时长
		可暂停、可倒退、可快进	、
